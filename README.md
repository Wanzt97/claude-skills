# Skills Claude de Wanzt

Mes skills pour Claude (Claude Code, claude.ai, Claude Design) : montage vidéo, YouTube, design et copywriting.
Gratuits, à télécharger et à adapter.

## Télécharger et installer
1. Télécharge le `.zip` du skill dans le tableau ci-dessous.
2. **claude.ai** : importe le `.zip` dans les réglages Skills.
   **Claude Code** : dézippe le dossier dans `~/.claude/skills/`.
