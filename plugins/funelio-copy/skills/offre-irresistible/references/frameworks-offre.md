# Frameworks d'offre — Référence

## Alex Hormozi — $100M Offers / Grand Slam Offer

### L'équation de valeur
```
Valeur = (Résultat rêvé × Probabilité perçue)
         ÷ (Délai × Effort & Sacrifice)
```

Pour créer une offre irrésistible, on joue sur les 4 variables :
- **Résultat rêvé** ↑ — rendre le résultat plus désirable, plus précis
- **Probabilité perçue** ↑ — garanties, preuves sociales, mécanisme logique
- **Délai** ↓ — raccourcir le temps perçu jusqu'au résultat
- **Effort** ↓ — réduire le travail demandé au client (le "fait pour toi")

### Les 4 piliers d'une Grand Slam Offer

1. **Identifier la niche** — aller dans une niche qui a argent, douleur urgente, et capacité de décision
2. **Créer le Dream Outcome** — formuler le résultat final de façon irréfutable
3. **Construire le Value Stack** — lister TOUT ce qu'on donne, nommer chaque élément avec bénéfice
4. **Réduire le risque** — garantie qui transfère le risque vers le vendeur

### Nommer les composantes (Hormozi Method)
Format : [Adjectif] + [Résultat] + [Mécanisme/Système]
- ❌ "Sessions de coaching" 
- ✓ "Système d'acquisition client automatisé"
- ❌ "Formation vidéo"
- ✓ "Bibliothèque de scripts de vente haute conversion"

### Types de garanties (du plus faible au plus fort)
1. Satisfaction (14-30 jours remboursement)
2. Résultat conditionnel (applique + obtiens, sinon remboursé)
3. Résultat garanti (on continue jusqu'au résultat)
4. Anti-risque total (on te rembourse + on fait le travail nous-mêmes)

## Russell Brunson — Value Ladder & DotCom Secrets

### Le Value Ladder
Le principe : chaque client entre par le bas de l'escalier (faible risque) et monte vers les offres premium au fur et à mesure que la confiance augmente.

```
BACKEND       → Offre high-ticket (coaching, mastermind, done-for-you)
                Prix : 5 000€ à 50 000€+

CORE OFFER    → Offre principale (programme, retainer, accompagnement)
                Prix : 1 000€ à 5 000€

UPSELL / OTO  → Offre complémentaire (outil, bonus, accélérateur)
                Prix : 200€ à 1 000€

TRIPWIRE      → Offre d'entrée (mini-service, audit, ebook payant)
                Prix : 7€ à 97€

LEAD MAGNET   → Gratuit (guide, checklist, mini-formation, diagnostic)
                Prix : 0€ (en échange de l'email)
```

### Les 3 types de trafic (Brunson)
- **Trafic qu'on contrôle** (publicité payante) → amener vers une opt-in page
- **Trafic qu'on gagne** (SEO, contenu organique) → amener vers une opt-in page
- **Trafic qu'on possède** (liste email) → le plus précieux, à construire en priorité

### La Perfect Webinar Formula (Brunson)
Structure pour convertir à un webinaire ou VSL :
1. Big Promise (promesse principale)
2. The One Thing (le seul concept qui change tout)
3. Stack (présentation du Value Stack)
4. Close (appel à l'action avec urgence)

### L'Epiphany Bridge
Méthode pour convaincre sans vendre : raconter l'histoire de sa propre transformation (avant → déclic → après) pour que le prospect s'identifie et veuille la même transformation.

## Matrice de décision — Quelle offre pour quel contexte ?

| Situation | Offre recommandée |
|---|---|
| Début d'activité, peu de preuves | Tripwire + garantie forte + sur-livrer |
| Expertise prouvée, peu de clients | Core Offer avec Value Stack musclé |
| Clients existants, peu d'upsell | Backend high-ticket + Value Ladder |
| Offre qui ne convertit pas | Audit 5 critères + repositionnement Dream Outcome |
| Prix trop bas perçu | Ajouter composantes Value Stack + renommer |
| Trop de refus sur le prix | Renforcer Risk Reversal + travailler objections |
